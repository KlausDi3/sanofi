─§ Quick "where do I look?" ─────────────────────────────────────────────

  🔍 New REST endpoint?    ──▶  hicode-api/main.py
  🔍 Tweak GPT prompt?     ──▶  main.py · create_system_prompt()
                                src/label_clustering.py · make_clustering_prompt()
  🔍 Embedding filter?     ──▶  main.py · filter_by_relevance()
  🔍 Add a UI panel?       ──▶  hicode-interface/src/components/<Section>/
                                wire into src/app/page.tsx
  🔍 Change API base URL?  ──▶  NEXT_PUBLIC_API_URL  in .env.local
  🔍 Add new dataset?      ──▶  drop a *.csv in syntheticdata/
                                (auto-discovered via /api/datasources)
  🔍 Run end-to-end?       ──▶  ./start-dev.sh
                                or per-package commands in README.md
